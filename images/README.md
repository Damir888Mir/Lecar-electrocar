# Фотографии для сайта

Положите фото в эту папку с такими именами — они автоматически появятся на сайте
(пока файла нет, на его месте показывается аккуратная заглушка «Место для фото»).

| Файл            | Где на сайте                         | Рекомендуемый формат      |
|-----------------|--------------------------------------|---------------------------|
| `about.jpg`     | Блок «О нас» (вертикальное фото)     | 1200×1500, JPG            |
| `gallery-1.jpg` | Галерея, большое фото                | 1600×1200, JPG            |
| `gallery-2.jpg` … `gallery-7.jpg` | Галерея            | 1200×900, JPG             |
| `og.jpg`        | Превью ссылки в WhatsApp/Telegram    | 1200×630, JPG             |

Советы: снимайте при хорошем свете, сжимайте фото (например, на squoosh.app) до 200–400 КБ.
